# ForsakenMoveset

This script displays a 1x1x1x1 moveset on the top left of the screen for Delta. It is designed to enhance the user experience by providing a clear and visible representation of the moveset, making it easier for players to keep track of their abilities.

## Installation

1. Open Roblox Studio.
2. Create a new script in ServerScriptService.
3. Copy and paste the contents of `DeltaMovesetDisplay.server.lua` into the script.
4. Save the script.

## Usage

The script will automatically display the moveset on the top left of the screen for all players when they join the game.
